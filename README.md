OLA Ride Booking Data Analysis 🚕📊

A data analytics project analyzing 100,000+ OLA ride booking records to uncover business insights related to customer behavior, revenue, cancellations, and operational performance using SQL and Power BI.

🔍 Objective

To simulate a real-world business analytics scenario by cleaning, querying, and visualizing large-scale ride booking data and presenting actionable insights through an interactive dashboard.

🗂 Dataset

Source: OLA ride booking dataset

Size: 100,000+ records

Format: CSV

🛠 Tools & Technologies

SQL – Data querying & transformation

Power BI – Dashboard creation & visualization

Excel / CSV – Data inspection & preprocessing

📁 Project Structure

Bookings-100000-Rows.csv – Raw dataset

Ola_Project.sql – SQL queries for analysis

OLA.pbix – Power BI dashboard file

📊 Key Analysis & Insights

1. Booking trends and ride status distribution

2. Top customers by number of rides

3. Revenue analysis by payment method

4. Vehicle type performance

5. Cancellation reasons and patterns

📈 Dashboard Features

The Power BI dashboard includes:

1. Overall booking overview

2. Revenue and customer insights

3. Cancellation analysis

4. Vehicle type distribution

5. Interactive filters for deep-dive analysis

🚀 How to Run

Import Bookings-100000-Rows.csv into your SQL database

Execute queries from Ola_Project.sql

Open OLA.pbix in Power BI Desktop to explore the dashboard
